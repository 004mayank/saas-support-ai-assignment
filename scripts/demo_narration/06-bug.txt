The Bug Investigator Agent receives a customer report and the changelog entries to search. Its matching rule is intentionally strict: at least two discriminating signals must align and there can be no material contradiction. A shared word such as export is not enough.

Here, a Chrome user reports that a CSV export for a one-hundred-and-twenty-day range stalls at ninety-two percent. One changelog entry is a Safari-only PDF problem. The other is a fixed CSV timeout for ranges over one year. The Agent correctly classifies this as new or unmatched. It then produces an engineering title, impact, environment, exact supplied reproduction steps, expected versus actual behavior, evidence, missing diagnostics, and duplicate-search terms. It never claims that engineering reproduced the issue, and it cannot create the ticket itself.
