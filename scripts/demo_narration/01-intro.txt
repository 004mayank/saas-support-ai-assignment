Welcome to Support Lab, my submission for the SaaS Support AI architecture challenge. The core design choice is simple: decide what behavior the business actually needs before deciding whether to build a Skill, an Agent, or ordinary software. This is a single-user web application. It starts in a safe demo mode, uses fictional data, and exposes every submitted component as an independent workspace. There is no coordinator, no hidden pipeline, no queue listener, and no system write. I will first explain the mapping, then run each Skill and Agent on its own.
