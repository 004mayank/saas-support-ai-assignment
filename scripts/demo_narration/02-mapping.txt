I applied one decision test consistently across all five capabilities. If a behavior must execute immediately and identically every time, especially on a safety-critical path, it is Neither. If it is a reusable, stateless procedure applied to one supplied input, it is a Skill. If it must reconcile evidence, manage uncertainty, or follow a conditional investigation, it is an Agent.

Ticket routing and emergency escalation is Neither. Outage, security, and legal keywords should trigger deterministic inbox and on-call rules before any model queue. A model can assist normal classification later, but it should not own that critical path.

Outbound replies become a policy-safe Skill. The at-risk customer briefing becomes an Agent because it synthesizes billing, usage, and ticket history. Ticket quality grading is a Skill because the rubric is stable; weekly sampling and scheduling are separate orchestration concerns. Bug investigation is an Agent because it must decide whether the evidence matches a known issue and then branch to customer guidance or an engineering handoff. The final count happens to be two Skills, two Agents, and one Neither, but that is an outcome, not a quota.
